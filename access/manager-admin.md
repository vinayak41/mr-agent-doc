# Manager and admin access

A user with the role `MANAGER` or the role `ADMIN` can access every query. That includes every [unallocated query](../topics/unallocated-query.md), for every source, every [team's unallocated query](../topics/teams-unallocated-queries.md), for every team, and every single query.

## Unallocated query

A `MANAGER` or an `ADMIN` can access an unallocated query for every source.

## Team's unallocated queries

A `MANAGER` or an `ADMIN` can access a team's unallocated query for every team.

## Single query

A `MANAGER` or an `ADMIN` can access every single query.
