# Access

Rules for who can access a query.

| Topic | Rule |
| --- | --- |
| [Team lead access to unallocated queries](team-lead-unallocated-queries.md) | A user with the role `TEAM LEAD` can access an unallocated query when its source is allowed to that user's team, or to that team's allowed teams. The same user can access a team's unallocated query when it is assigned to that user's team, or to one of that user's allowed teams. |
| [Manager and admin access to unallocated queries](manager-admin-unallocated-queries.md) | A user with the role `MANAGER` or `ADMIN` can access an unallocated query for every source, and a team's unallocated query for every team. |
