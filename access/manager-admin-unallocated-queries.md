# Manager and admin access to unallocated queries

A user with the role `MANAGER` or the role `ADMIN` can access every [unallocated query](../topics/unallocated-query.md), for every source. The same user can access every [team's unallocated query](../topics/teams-unallocated-queries.md), for every team.

## Unallocated query

A `MANAGER` or an `ADMIN` can access an unallocated query for every source.

## Team's unallocated queries

A `MANAGER` or an `ADMIN` can access a team's unallocated query for every team.
