# Index

Business rules for how a query moves through the sales process. Each page states the rule, when it applies, and what stays unchanged.

| Topic | Rule |
| --- | --- |
| [Primary query](features/primary-query.md) | Among a contact's queries, the primary one is not LOST, BOOKED, or CANCELLED, and it has an assigned employee. |
| [Call log sets sales stage](features/call-log-sale-stage.md) | A new call can move the primary query from NEW to CONTACTING or CONNECTED, based on call length. A short call leaves CONTACTING as it is. Any later stage is left unchanged. |
