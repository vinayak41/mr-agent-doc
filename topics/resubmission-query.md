# Resubmission query

A contact can have more than one query. When any of them has an assigned employee, each other query with no assigned employee is a resubmission query.

## How it is recognized

A query is a resubmission query when all three are true:

1. The contact has more than one query.
2. At least one query for that contact has an assigned employee.
3. This query has no assigned employee.

A query with an assigned employee is not a resubmission query. If no query for the contact has an assigned employee, none of them is a resubmission query. If the contact has only one query, that query is not a resubmission query.
